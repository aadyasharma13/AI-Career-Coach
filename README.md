# AI Career Coach – Smart Resume Analyzer


AI Career Coach is a Flask-based web application that leverages advanced language models (Claude or OpenAI) to automatically analyze resumes and provide professional summaries. It extracts key information such as career objectives, skills, experience, education, and achievements to help job seekers optimize their resumes for career success.

## Features
-  Upload a PDF resume and receive an AI-generated summary.
-  Smart text splitting and semantic search using FAISS.
-  Query your resume with custom questions using Retrieval QA.
-  Supports Claude (Anthropic) or OpenAI models via LangChain.
-  Simple, intuitive web UI using Flask.

##  Technologies Used
- **Python**, **Flask**
- **LangChain**, **FAISS**
- **Claude API (Anthropic)** / **OpenAI API**
- **PyPDF2**, **pdfplumber**
